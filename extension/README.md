# Style It Yourself for Chrome

Capture a clothing item from any store page and add it to your Style It
Yourself closet, or match it against what you already own.

It is not on the Chrome Web Store yet, so for now you install it by hand. It
takes about a minute.

## Install

1. Download **[siy-extension.zip](https://github.com/Paullitsc/Style-It-Yourself/raw/main/extension/siy-extension.zip)** and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and select the unzipped folder.
4. Pin the extension, open any product page, click the icon, then **Connect**
   to sign in.

To update later, download the zip again, unzip it over the old folder, and
click the refresh arrow on the extension's card in `chrome://extensions`.

You need a free account at [styleityourself.ca](https://styleityourself.ca).

## What it does

- **Add to closet** reads the product's image, title, brand, and price,
  suggests a color and category, and saves the piece to your closet.
- **Check match** shows which pieces you already own pair with the item.

The extension only reads a page when you ask it to, and only talks to Style It
Yourself.
